# i18n/ — 本原型的翻译表

> 本文不写约束句（「约束唯一出处」）；约束句一律写成 契约名 指针，此处只留事实、机制与操作步骤。

一个原型一份 CSV，文件名与原型目录同名（模板这份是 `_template.csv`，接新原型时改名）。
机制与判据见 `docs/GugaFramework/i18n.md`。

## 表的形状

```csv
keys,en,ja,fr,de,es,ru,ko
"重开一局",,,,,,,
"战斗中 · 第 {0:F1} 秒 · 存活 {1}/{2}",,,,,,,
```

- 八列固定：首列是中文原文（也就是代码里 `Loc.T` / `Loc.Fmt` 传的那个键），其余七列留给译者。
- 键一律用双引号包住 —— 内部有逗号（`定价 ${13}(, / .)`）时读取器才认得。
- UTF-8 无 BOM、LF。伴随文件 `_template.csv.import` 要提交（「伴随文件入库」）。

## 两条会当场拦下你的测试

`GugaFramework/Tests/I18nRuleTests` 按 `Prototypes/*` 逐个原型扫，两条都跑：

| 判据 | 红了说明 |
|---|---|
| `Loc传的中文键都在表里` | 代码里上了 `Loc` 的文字没登记进表 —— 译者拿不到它 |
| `表里没有孤儿键` | 表里的键在 `.cs` 与 `.tscn` 里都找不到出处 —— 要么代码改了没同步删键，要么键打错了 |

**所以表里放不了格式示范行。** 示范文字既不在源码里（判孤儿），也不是任何 `Loc` 的键，
两条都会红。格式示范写在这份 README 里，不写进 CSV。模板这份表里那一行「重开一局」
是 `Scripts/Main.cs` 的 `SetupFrontEnd` 真正用上的键，所以两条都过。

## 接新原型

1. 把 `_template.csv` 复制成本原型的表名。
2. 键按代码里实际 `Loc.T` / `Loc.Fmt` 的调用逐条登记，登记完跑一次 `I18nRuleTests` 验两条判据。
3. 键数与表路径的读数记在 `docs/prototypes/<原型>/`（那边才写逐原型的数字，「框架文档零原型」）。
