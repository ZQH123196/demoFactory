# 体检单比例尺同框按占地档分组

模型体检单栏 3 的比例尺同框按占地档分组：原型声明若干组，每组一行、组内同一像素比例。

## 问题

栏 3 的原口径是「同一原型的全部模型排一行，脚下铺方格网」。模型清单变大后，行长按单件宽度线性增长；出图宽度固定时，单件的像素宽按件数反比缩小，网格线间距先落到亚像素，整张图退化为灰场。

只放大相机远裁剪面不能恢复可读性。远裁剪面只决定「画不画得进来」，不决定「画进来以后认不认得出」。放大画布也只能线性补偿：件数继续增长，像素宽继续按件数反比下降。

## 决定

`ReviewContract` 增加 `ScaleGroups`：原型可声明若干组；每组含组名、模型表与网格步长；每组仍排一行，组内按该组声明的网格。

分组口径：

- 组内最宽与最窄的占地宽比不超过约 10 倍。
- 最窄件在约定出图宽度下至少 20 像素。
- 未声明 `ScaleGroups` 的原型维持旧的单行路径与产物名；产物按组命名，报告列出每组。

## Considered Options

- **保留单行，放大画布与远裁剪面**：像素宽按件数反比下降，放大画布只能线性补偿，网格仍会落到亚像素。不足。
- **所有原型统一多行分页**：组内可比、组间不可比，且其他原型报告全部变化。不取。
- **按占地档分组，组内一行**（本轮选这个）：组内保持同一像素比例，组间靠体检单数字比较。代价是栏 3 从「原型一张图」变成「按组多张」。

## Consequences

- 栏 3 的口径改为「组内一行、组间读数比较」。
- 采集器与编排层的组字段、按组产物名由公共层提供。
- 未声明组的原型，行为与报告不变。
- 分组表是原型自己的数据，不进公共层；公共层只提供组字段与采集能力。
