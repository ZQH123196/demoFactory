# 悬停裁决由模块推送，候选点不进 Journal 与检查点快照

候选点输入口在模块上。表现层在鼠标动时推**手势描述**（蓝图或布局文本、候选点、方向、批量形状），
不是每帧轮询；模块吸附/量化后**去重**——手势描述不变则零计算零事件，变了才跑完整校验并推送悬停
裁决事件。占用变化（提交 / 移除 / 摧毁）时对当前手势重算，裁决变了才推。三条不进：不进 Journal
（这个口是 call 类，「写路径进 Journal」）；不进检查点快照（「试验场随技能层」 机位不进快照同款口径）；Commit 显式
自带候选点参数、不消费悬停值（Journal 录参数，重放自包含）。配套契约（**预览一致性**）：表现层
显示「能不能放、落在哪、占哪些格、什么角度」的一切只准读裁决流，禁止第二次计算；网格 gizmo 的
格长 / 边界 / 量化步长从模块只读查询取——画出来的网格与逻辑判定的网格是同一组数。

送达机制是纯 C# 事件（推送式，typed record 带步号）：R3 已从仓库移除，
生成/消费分离那条原则保留，落地形状按纯 C# 事件。

## Considered Options

- **每帧拉式 Check**（迁移前的形状）：表现层每帧算一遍合法性，且手写一份逻辑层镜像
  靠注释维持「同源」——靠注释维持的同源会漂；用户明确拒绝这个形状。
- **表现层自己去重再拉**：去重逻辑散在表现层，合法性又有两处真值。
- **技能层账本式出口**（事件追加进世界账本、消费者排空）：拉的一面回来，与事件驱动诉求相抵；
  写路径的行为流已由 Journal 承担，事件账本不必再担一遍。

## Consequences

- 「幽灵红绿」成为离线可断言命题：推手势 → 断言裁决事件，`dotnet test` 级，
  不再是只能靠 MCP 出图验证的表现层事项。
- 重放剧本从头到尾不含悬停；快照里没有悬停段——视图侧状态在确定性面上零存在。
- 宿主迁移时删掉那份逻辑层镜像与 ghost 预览的每帧合法性计算。
- 送达机制 = 推送式 C# 事件，typed record 带步号；形状口径照 ADR 0001（一个 kind 一个类型、
  无可选位）。生成/消费分离那条原则不变（「C# 优先与总线」）。
