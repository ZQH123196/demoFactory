# 时间旋钮不进账也不进快照

暂停、单步、变速这三样时间旋钮，**不进 Journal、不进检查点快照**。
玩家控制节奏不是世界演化。

## Considered Options

- **时间旋钮进 Journal**（当普通命令录）：重放端得识别这些动词并复现玩家按过几次暂停。
  但重放端要做的事是「推进到目标步」，玩家按暂停这个动作对那个循环没有意义。
  且暂停会挡 `Advance`（`GameClock.cs:146`），**暂停与否改变后续 tick 的推进节奏**——
  一条账也救不了中途快照之间的空档。
- **时间旋钮只补进快照、不进 Journal**：快照通常只在关键点抓，
  「这一段之间玩家暂停过几次」在两个快照点之间仍然不可知。而且与契约矛盾——
  `GugaFramework/Tests/NavStageTests.cs:202` 已有一条测试叫「时间控制不进快照」，
  它断言 `Speed=0.25` + Pause/Resume 之后快照逐字不变。
- **既不进账也不进快照**，把「玩家控制节奏不是世界演化」定成口径：本轮选这个。
  三处原型已证明重放端不需要知道玩家暂停过——无限领主 `ReplaySetup.cs:141`
  与巨兽竞技场 `BeastArenaWorld.cs:180` 的 `AdvanceTo` 都是守暂停的无脑循环。
- **顺带把三套 `AdvanceTo` 收编成一份**（`0014` 的延续）：
  现在无限领主与巨兽竞技场守暂停、排兵布阵用 `AdvanceDebugSteps` 暂停也照走，
  同一件事三套循环。收编成一份「推进到目标步」，是「重放装配单源」那条契约的自然延伸。

## Consequences

- 三处快照头部行（`LogicWorld.cs:2409-2410`、`BattleWorld.cs:928-929`、
  `BeastArenaWorld.cs:550`）**保持只有 `tick` 没有 `paused`**，不改。
- 倍率继续留在表现层 `SpeedControl`（不进快照、不进 Journal）。
- 玩家命令仍进 Journal（`0014`）——本 ADR 只管时间旋钮这一类。
- 测试里补一条显式断言，把「时间旋钮不进账不进快照」从 `NavStageTests.cs:202`
  那一条间接测试升成本轮的直接断言。现在 13 条暂停测试断的都是世界行为，
  没有一条断暂停这个控制动作本身的记录待遇。
