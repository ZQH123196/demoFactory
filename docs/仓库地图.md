## 目录结构

```
src/            # 全部代码根目录（「源码归 src」）
  GugaFramework/  # 公共层：Base、EventBus、Scheduling、Pathfinding、Construction、Entities、Abilities、
                  #   FrontEnd、Persistence、Vfx、Replay、DebugBridge、Guard、Camera、Animation、I18n,
                  #   Input、Composition、ObjectPool、Tools/glb、beehave/（vendored，不改写）、Tests/。
                  #   各层 → docs/GugaFramework/
  Tools/        # 不进游戏的 C# 工具项目，被游戏 csproj 显式排除；review 工位在这
  Shared/       # 共同依赖②（代码以外）：跨原型共享的模型、贴图、音频
  Prototypes/   # 原型隔离区（「原型隔离」）；_Template/ 是脚手架
docs/           # 文档；prototypes/ 各原型一一对应，GugaFramework/ 机制说明，agents/ 技能三页配置
  adr/          # 架构决策记录（仓库级，不是某个原型的设计）
  research/     # 研究探针与调研留痕
  我的开发手记.md  # 禁止读写（「私人手记禁触」）
.scratch/       # 施工规格与 ticket（gitignore）；结论并进 docs/ 后即删
.cache/         # 探针、离线产物、出图（gitignore）；代码里那一头见 src/Tools/Artifacts.cs
```
