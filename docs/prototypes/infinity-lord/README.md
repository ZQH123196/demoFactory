## 快速事实

- **玩家写入口三个**：挂悬赏旗（花钱）/ 同目标加价 / 放置建筑与升级行会——仍无任何直接命令。
- **英雄完全自治**：勇气评估（赏金 vs 危险，职业系数修正）自主决定是否出工。第一名游侠的决策改由行为树给（技术账见 `docs/GugaFramework/行为树与跨语言共存.md`）。
- **建筑即招募**：游侠/战士公会可放置，建什么产什么职业；翻倍计价、每会名额 4。
- **一局有始有终**：宫殿被毁 = 失败，摧毁 BOSS 巢穴 = 通关；三波剧本加压、3:30 终幕降临，约 8 分钟。
- **金币循环**：赏金 → 市场消费 → 40% 税收回流金库；村民税保底入账，无维护费。
- **需求流失**：赏金/酒馆饥饿任一满 300 步 → 冒险者自利离队。
- **时间轴**：离散步进（10 步/秒），暂停后世界冻结。
- 旧设计「玩家利用 AI 性格缺陷通关」已被用户否决，方向是复刻 Majesty 2。
