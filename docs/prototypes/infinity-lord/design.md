# 无限领主 — 设计思路

> 约束句一律写成 契约名 指针（「约束唯一出处」）。全局基准见 `docs/prototypes/各原型设计初始基准.md`，本文是该 demo 的具体化。

## 1. 核心幻想

**「我是领主，但我说了不算——钱说了算。」**

玩家扮演一座边境要塞的领主。英雄不是士兵，是拿着剑的自由职业者，有自己的钱包、勇气和算盘。玩家能做的只有一件事——**把金币挂在任何想解决的目标上**，看着这些唯利是图的家伙权衡「赏金 vs 性命」后自行其是。

## 2. 体验支柱（玩家在追求什么快感）

来自基准表二 A 类「构筑与验证」：**「我真聪明」的解题感**。

- **间接控制的博弈感**：玩家不能命令任何单位，唯一动词是「出价」。悬赏要能可预期地改变 AI 行为。
- **AI 行为可预期**：决策链固定且可读——勇气公式公开、战损惜命；同样输入 → 同样行为。
- **定价即策略**：悬赏定价是核心旋钮，太低没人接、太高破产；玩家要能读出「行情」。
- **经济闭环的压力**：赏金出去→税收回来，金库是弹药库；形成「入不敷出→定价权衡」。

## 3. 核心循环

```
怪物从巢穴涌出 ──▶ 玩家的城堡 ──▶ 税收回流金库
   ▲                                      │
玩家评估定价 → 挂悬赏旗 → 勇气评估         │
   │            │                         │
   └─ 承接攻坚 ◀┴─ 否 ▶ 继续巡逻，玩家加价
        ▼
   目标死亡 → 赏金支付 → 英雄消费 ────────┘
        └──── 威胁升级 / 新巢穴出现 ◀────┘
```
## 3a. Majesty 2 循环解析 — 三层嵌套结构

3 节画的是**内环**。Majesty 2 本尊是三层嵌套，每层转速不同。
### 内环（秒级~分钟级，转无数次）— 悬赏经济环

即 3 节的闭环，已验证成立。**但在 Majesty 2 里这只是燃料**。
### 中环（分钟级）— 英雄供应链环

玩家花钱建基础设施 → 英雄自己赚钱、在玩家的店里买装备 → 变强 → 敢接更硬的单。**两个独立钱包共享同一条经济动脉**：铁匠铺不是你的军备，是英雄的军备。
### 外环（局级，一局游戏）— 威胁升级与终局环

剧本定期加压：小怪骚扰 → 巢穴激活 → 波次进攻 → 精英 → BOSS。宫殿是税收集线兼失败条件。
### 爽点在哪（三环齿轮的咬合处）

- **「我赌对了」**：挂赏是对 Agent 行为的下注，确认感来自算对了公式。
- **可读的失败**：英雄死了不是随机——钱包空、士气低、赏金没到位。
### 自走战斗型的一般化循环（跨品类骨架）

Majesty 2 / TFT / Loop Hero / 塔防共享同一骨架：**构建（下注配置）→ 自动执行（只看）→ 结算（输赢可归因）→ 滚雪球**。

**关键洞察：战斗不是玩法，战斗是考卷。** 玩家玩的是「构建」，自动战斗只是批改答案。Majesty 的独特之处是做成**连续实时**。
### 原型差距对照

- **内环（悬赏经济）**：完整，且经守恒测试逐步审计。
- **中环·英雄侧成长**：悬赏即 XP、击杀+15XP、装备 $20/级——复利链成立。
- **外环（威胁升级+终局）**：剧本波次表 + 失败判定 + BOSS 胜利判定全部落地。
### 对生死线大考的影响

生死线命题「仅靠发悬赏能否策略**通关**」操作定义缺失，根因正是外环不存在。最小形态四件：① 城堡实体；② 威胁曲线；③ BOSS；④ 玩家侧纵向成长。

**已回答**：全动词 7:09、只挂赏 7:45 通关，零干预 6:36 判负。**答案：能通关，也能输。**
### 基线长跑实测 — 闭环健康检验已完成

两条确定性长跑（`BaselineLongRunTests` / `BountyOnlyLongRunTests`，seed 42、6000 步）。**结论：循环健康。**

| 指标（6000 步终局） | 零干预 | 只挂赏（$30 响应 + 建议价清剿） |
|---|---|---|
| 英雄 | **0**（600 步内全灭 18 名） | 3~4，超级游侠 Lv.19 装备 29 |
| 存活怪 | **387 无界堆积**（+40/600 步） | 0~4 动态平衡 |
| 玩家建筑 | 全毁（仅剩巢穴） | **全保** |

零干预下怪物产能打穿生态承载力；只挂赏结构脆弱、赢者通吃集中在单一超级英雄。

## 4. 验证命题（本原型要回答的问题）

基准表一给的生死线：**仅靠发悬赏给行为模式可预期的 AI，能否策略通关。**

| 切片 | 回答的子命题 | 结论 |
|---|---|---|
| 1 中台 | 离散步进 + 逻辑/表现分离 + 暂停能否撑住模拟 | 通过 |
| 2 悬赏 | 「出价」一个动词能否驱动全部交互 | 通过（9 英雄轮替攻坚） |
| 3 经济压力 | 金币循环能否形成真实定价压力 | 通过（军饷机制已删） |
| 4 成长 | 英雄 RPG 循环是否与「发悬赏」产生化学反应 | 通过（悬赏=装备来源） |
| 10 终局 | **生死线原命题** | **能通关，也能输**（7:09 / 7:45 / 6:36） |

### 各片结论补记

| 片 | 结论 |
|---|---|
| 5 行情 | 悬停显示与勇气公式逐字一致（地精 16 / $20、巢穴 300×0.02=6 / $8） |
| 6 虚空黄金 | 英雄自养闭环成立，悬赏从「唯一收入源」变成加速器（`KillLootGold = 8`） |
| 7 需求 | 挂旗窗口内低士气英雄接单率 **0/57** |
| 插队小项 | 巢穴摧毁后 `LairRespawnDelayTicks=150` 远端重生（血 300），选址是确定性纯函数；建筑扣血单一入口 `DamageBuilding` |
| 7+ 排期 | 定价的职业分化成立（$18 只有战士承接、$30 游侠立即承接） |

### 行为树那两条实测教训

- 「安全之后干什么」取随机游荡时，逃跑在「已拉到安全距离」那一刻要返回 FAILURE。原先返回 SUCCESS 让它永远赢，占比从 73 掉到 2。
- 全世界共用一条 `Random`，一名英雄行为一变，后面所有人的抽签跟着变。全量 diff 不能当归因工具，复验要比行为流。机制与技术账 → `docs/GugaFramework/行为树与跨语言共存.md`。


## 5. 生死线与红线

### 绝对不能破

1. **不出现直接命令单位的交互**。玩家能写的数据只有：悬赏旗金额、建筑放置。
2. **AI 可预期但不必然服从**。英雄会拒绝低赏金、会惜命，但拒绝原因必须事后可解释。
3. **不出现玩家绝对挫败**。AI 随机到「挂赏也没人来」时必须有清晰可读的原因。

## 6a. 设计决策 — 军饷/维护费概念删除

用户原话：「**没有军饷这个概念，里面的都是冒险者。**」（已定稿）

**决策**：军饷/维护费机制整体删除——冒险者完全自雇，连带删除破产脱队潮与招募冻结。

**人口托底换引擎**：原「军饷膨胀→破产哗变→兵力回落」的系统性放血改为**需求流失**：

| 计时线 | 「饿」的定义 | 清零 |
|---|---|---|
| 赏金饥饿 | 连续零收入 | 承接旗子 / 任何进账 |
| 酒馆饥饿 | 想喝（士气 < 60）却喝不上 | 想喝但有钱 |

任一线满 `NeedStarveLeaveTicks=300` 步 → 离队（事件 `HeroLeftNoBounty`/`HeroLeftNoTavern`）。离开的是「饿」的人。

**语义变化（设计层，勿当 bug 修）**：金库从「血条」变「弹药库」。切片 3 那条「繁荣→破产→自愈」周期不再存在。
## 7. 实测观察（历史 — 军饷机制时期）

以下观察基于已删除的军饷机制，保留作为切片 3 历史教训。

放任不管时世界自然经历「繁荣→军饷膨胀→破产哗变→兵力回落→复苏」的完整经济周期（均衡兵力约 12 人）。军饷机制验证了「金库是血条」的压力模型成立——删除它是叙事自洽性决策。
