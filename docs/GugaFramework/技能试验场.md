> 术语用 `GLOSSARY.md`「技能层」的词表。约束句的唯一出处是 `AGENTS.md`「契约索引」。
> 本页只记事实、机制、操作步骤、实测数字、设计结论与待确认项。
> spec 在 `.scratch/skill-stage/spec.md`，本轮过程证据在同目录 `notes/`。

**落点**：`src/GugaFramework/Abilities/Stage/`（逻辑壳 + 场景壳 + 注册口 + 示范注册壳），不隶属任何原型；离线用例在 `src/GugaFramework/Tests/`。**三个观测口**：时间可控（步，1 步 = 0.1 秒，「时间基准」）／状态可查（一发快照）／行为可注入（唯一写路径）。**三条口径**：通用、理想、固定。

## 公共层：距离从宿主来，单位身上不再有坐标

距离由宿主给，两条路都能用：**宿主递标量**（`TryActivate(unitId, abilityId, targetId, distanceMeters)` / `UnitsInRange(unitId, radiusMeters, distanceMeters)`，距离是常数时用）与**注册谓词**（`AbilityStepper.DistanceOf = (fromId, toId) => 米`，距离要现算时用）。调用点递的标量优先，没递才问 `DistanceOf`，**两条都没有就当场抛 `KeyError`**——兜 0 等于静默判成贴脸；`Distance(fromId, toId)` 是层对外问距离的那一发。
**位移意图**跟着变成一对标量：`CastAbility` 第 4 段形状是 `从>到`（例：`p01|warrior.rift|e01|1>3.5`），只给一个数当场抛；`TryMove` 只剩激活检查，坐标由宿主写进自己那份世界。

`dotnet build -t:Rebuild` 0 警告 0 错误，全量 `dotnet test` 全部 0 失败。

### 场子那一侧怎么用

`SkillStage` 把摆位收在自己那份（`StageUnit.X` + 场子内部的站位表），距离经 `DistanceOf` 递进去；表现层要读站位读场子（`SkillStage.XOf`），层里读不到——这是换二维场子时唯一要动的那一处。

- **注入命令线上格式变了**：第 4 段从 `3.5` 变成 `1>3.5`，仓外手写的老格式当场抛 `FormatException`。

## 第一个场子：场地条件兑到「理想」那一档

三条口径里的**「理想」**到这一期补齐：远近都摆得出、二维站位与扇形摆得出、能钉住单位、能停能慢放、无天气经济 UI 干扰。

### 场地条件

| 条件 | 形状 | 落在哪 |
|---|---|---|
| 摆位 | **二维** `(X, Z)`，米 | `StageUnit.X` / `StageUnit.Z`（注册口递进来） |
| 朝向 | 一格角度，0 = 朝 +X，90 = 朝 +Z | `StageUnit.FacingDegrees` |
| 距离 | 两点欧氏距离，**一份实现** | `SkillStage.DistanceBetween`，经 `DistanceOf` 递进层 |
| 扇形 | 公共层那把尺，场子只递标量 | `SkillStage.TargetsInSector` → `AbilityStepper.InsideSector` |
| 阻挡 | **没有** | 场地是平的，场子不持任何阻挡表 |

朝向换算成两个标量喂 `InsideSector`，换算在 `FacingVectorOf` 一处。

### 时序三个口

| 口 | 作用 | 暂停中 |
|---|---|---|
| `AdvanceRealSeconds(真实秒)` | 表现层每帧那一发：倍率乘在流速上，攒够一步才推一步 | 零步 |
| `Advance(n)` | 批量推进（时间流） | 一步都不走，返回 false |
| `AdvanceStep()` / `AdvanceDebug(n)` | 单步调试口：**暂停中也照走** | 照走 |
| `Speed` | 倍率，换算走既有 `SpeedControl`（每秒 10 步） | — |

**倍率给 0 当场抛**，不兜默认值。**暂停与倍率不进快照**，想看它们读属性（`IsPaused` / `Speed`）。

### 位置钉得住怎么兑现

场子**不替单位走位**：没有自动寻敌、没有自动靠近，位置只由注册口那份开局摆位与注入 `Move` 那一发改。`Move` 只带一个标量（`单位Id|走几米`），所以走 X 那根轴、Z 不动；场景壳另画一段 2 米的朝向短线，**扇形界内界外那几格肉眼要能复核，靠的就是它**。

### 实测数字

build 0 警告 0 错误。射程 3 米时 0.5 / 2.99 / 3.0 米放得出，3.01 米当场拒（`NotInRange`）。

### 边界与待确认项

- **`Move` 仍只走 X 一根轴**：二维位移摆不出来，要动公共层动词表。
- **场景壳那一侧未经出图复核**：色带落点、朝向短线、网格中轴三项留给出图那一期。

## 机位三套预设

场子自带机位补到「三套预设 + 点谁跟谁 + 手动兜场」，落点全在场景壳 `SkillStageScene.cs`（**零新文件**）。三套：`overview` 全景（场地中心，`FitDistance(场地边长, 78°)`，不跟随）、`follow` 跟随（锁定那个单位的脚下，`FitDistance(14, 58°)`）、`closeup` 特写（同上，`FitDistance(5, 42°)`）；手算与运行时读数逐格相同（40 米见方 / fov 75 / 16:9）：**28.3 / 8.6 / 2.4**。

### 三套与那些数从哪来

`FitDistance(span, pitch)` 取横向与纵深两条约束里更远的那个，`fill = 0.9` 留一圈空白；fov 从场景那台相机读、画面比例从视口读（`fov=75 aspect=1.778 fill=0.9`）。改 `GridHalfExtentMeters` 全景距离就跟着走；相机距离范围 `MinDistance 1.5`、`MaxDistance = max(140, 全景×3)`。

### 入口：换预设 / 换锁 / 微调

切预设：键 1 / 2 / 3（action `stage_view_overview` / `stage_view_follow` / `stage_view_closeup`）或 `ApplyViewByName`。换锁：Tab（抛 `FollowToggleRequested` → `CycleLockUnit`）、中键单击（`PickUnitAt`）或 `FollowUnit("单位Id")`。微调：滚轮 / WASD / Q E / ↑↓ / 中键拖拽，或 `NudgePose(距离, 偏航, 俯仰, 平移X, 平移Z)`。读数：右上角第三行，与 `ViewReadout()` 同一份。
`PickUnitAt` 取屏幕距离最近那块色带，认不到不动、名字不认识当场抛；`NudgePose` 在跟随状态下收到平移**会解除锁定再挪**。`StartView` 是场景配置而不是动词，不在词表里、不进 Journal。

### 注册壳那份多了一个形状

`SkillStageSample.SpecMultiUnit()`：六个单位散在场地里（出手与挨打仍贴 3 米，其余四个离 12 米），场子默认跑这一份，因为「点谁跟谁」「全景看群体」要五六个人同框才验得出来；`Spec()`（1 打 1）原样留着，离线台账与清单仍走它。

### 出图复核带出来的三处改动

三样都是出图量出来的、不是审美偏好：**名牌与标尺刻度的字高按机位距离缩放**（比例 = 相机距离 ÷ 28.3）；**名牌离地 1.6 米 → 0.9 米**；**名牌逐个错开 5 米 → 1 米**。

### 机位不进快照 / 不进录制

逻辑壳三份源码里 `camera / focus / yaw / pitch / preset / follow / zoom` **零命中**，`AbilityVerbs.Names` 九个字面量逐个扫同一批词也**零命中**——切预设 / 换锁 / 挪镜头走场景壳自己的方法，没有一条经过 `SkillStage.Inject`。S24 把这两条钉成用例。

### 边界与待确认项

- **`input_action` 注入切预设没成功**（`sent: true` 而读数未变）：判为 `is_action_just_pressed` 的帧竞争；要判清得用帧级时间线那一档（`input_sequence`）。

**该宿主碰到的三处**：① 效果由宿主发起的那条路要显式声明（`AcceptsCastDestination = false`，给了第 4 段当场抛）；② **冷却中按下会排队**（N-16），转好那一步会补放；③ **回血与伤害共用一个 `hp` 列**，宿主每次出手前后各抄一次，不抄的话同一逻辑步里先喝药再挨打会把那一笔回血抹掉。

### 冷却尺当唯一真值：技能行写卡上那个数

上一层落地时层里那把尺比卡上少一步（层的冷却从 commit 起算，commit 排在按下之后一步），技能行因此写成「卡上间隔 − 1」；后来把口径翻过来，**技能行直接写卡上那个数**，技能表里那处 `- 1L` 删掉。做法是公共层新增一格 `AbilityLayerConfig.InstantCommitOnPressStep`：设 `true` 时按下那一步就过 commit 点；**缺省 `false`** 是「按下之后等下一步的 S3 才过 commit」。这一档最终做成宿主可选，因为做成无条件之后有宿主的用例各早一步红。

对齐由用例 `出手的步差与卡上的出手间隔逐字相同` 钉住。逐宿主那一行与那几条用例的读数记在 `docs/prototypes/<原型>/`。

### 建筑进技能目标域

**建筑以「宿主显式声明的身份」进层那一册**。公共层不认识「建筑」这个词：身份只住在原型侧一张 Id 表，层那一册只管「这个 Id 在不在、打不打得到」。
**接口那一格**：`IAbilityHost` 加 `Exists(id)`，五个宿主各自实现，激活检查里排在射程之前，拒的理由叫 **`AbilityRejectReason.TargetGone`**——目标中途被拆是「这一位不存在」，不是「打不着」，两件事的理由分开。**两处收口**（建筑进册之后才可达）：① `TargetFor` 查不到时不再静默回退成施法者，现在当场抛；② 层里目标查不到时不再回退，硬索引那一格改成有名字的拒绝理由。
**一处真缺陷：逼近阈值那 1 米容差**。建筑那一侧原先写成 `gap > AttackRange + 1` 才逼近，而层按技能表那一份射程判，两把尺差 1 米的那条带里世界不逼近、层也拒，症状是「围着楼站着一步不出手」，账上只看得出伤害变少；改成与单位那一侧同形：逼近与出手共用层那一份数。
